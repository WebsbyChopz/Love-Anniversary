ARUN — LOVE ANNIVERSARY WEBSITE
================================

Files:
- index.html
- style.css
- script.js

Preview locally:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.
3. Internet is only needed for Google Fonts and the optional Unsplash hero photo.
   The layout, letter modal, animations and buttons are local.

Publish with GitHub Pages:
1. Upload index.html, style.css and script.js directly to the repository root.
2. Open Settings > Pages.
3. Select Deploy from a branch, branch main, folder /(root).
4. Wait for deployment and open the published Pages URL.

PERSONALIZE BEFORE SENDING:
- Replace “My Love” / “my favourite person” with the girlfriend’s name or preferred nickname.
- Confirm the anniversary wording and date with the client. First meet is shown as 19 October 2023.
- The brief says “4th love anniversary”; check whether the relationship anniversary date differs from the first-meet date.
- Replace the remote photo URL in style.css with a photo the couple has permission to share, if they want a personal image.
- The “Play our little melody” button is only a placeholder until you add a licensed audio file and set `audio = new Audio("music.mp3")` in script.js. No music is bundled.

The copy is intentionally editable and avoids claiming specific memories that were not supplied by the client. Ask the client for the girlfriend's name, relationship start date, nicknames, 2–3 real memories, and preferred language before final delivery.
